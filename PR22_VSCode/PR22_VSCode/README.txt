Практическая работа 22. PHP 8.1 или новее.
Откройте папку PR22_VSCode в VS Code. В терминале проверьте php -v.
Запускайте задания отдельно, чтобы одноимённые классы не конфликтовали:
php task1/index.php
php task2/index.php
php task3/index.php
php task4/index.php
php task5/index.php
Composer и сторонние библиотеки не нужны. results.txt содержит фактический вывод.
